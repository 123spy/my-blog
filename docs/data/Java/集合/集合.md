# Java集合

## Collection(单列集合)

### List

 注：

List代表了有序可重复集合，可直接根据元素的索引来访问

此处的有序，代表的是。我插入的a c b，取出来的还是a c b。（正确）

容易误解：插入的a c b, 取出来是a b c。（错误）

#### ArrayList

**特点**

- 底层：动态数组
- 支持下标访问 `get(i)` 很快（O(1)）
- **尾部追加**快，**中间插入/删除**慢（要搬移元素）

**适用场景**

- 读多写少
- 需要频繁随机访问

#### LinkedList

**特点**

- 底层：双向链表
- **中间插入/删除**相对更合适（不搬移数组），但要先定位节点
- 随机访问慢（O(n)）
- 实现了List，Deque。可以用来实现队列与栈

**适用场景**

- 更偏“队列/栈”用法（头尾操作多）
- 需要频繁在头尾插入删除

#### Vector

**特点**

- 类似 ArrayList，但方法很多是 `synchronized`（线程安全）
- 性能通常不如 ArrayList

**建议**

- 现在大多不用 Vector
- 多线程更常用：`Collections.synchronizedList(...)` 或并发容器（如 CopyOnWriteArrayList）

### Queue

注：

Queue是队列集合

#### LinkedList

可做队列：`offer / poll / peek`

可做双端队列 Deque：`addFirst / addLast`

#### PriorityQueue

**特点**

- 底层：堆（最小堆默认）
- 每次 `poll()` 取出“优先级最高”的元素（默认最小）
- 插入/删除 O(log n)

**适用场景**

- TopK、调度、按优先级处理任务
- 中位数、合并多个有序流等经典题

## Map(双列集合)

注：

Map代表的是存储key-value对的集合，可根据元素的key来访问value。

### HashMap

**特点**

- 底层：数组 + 链表/红黑树（JDK8 以后冲突严重会树化）
- 平均 O(1)
- 允许 `null` key（1个）和 `null` value（多个）
- 线程不安全

**适用场景**

- 绝大多数键值映射

### TreeMap

**特点**

- 底层：红黑树
- key 自动排序（自然顺序/Comparator）
- O(log n)
- 提供范围 API（非常强）：`floorKey/ceilingKey/subMap/headMap/tailMap`

**适用场景**

- 需要按 key 排序、做区间查询

### HashTable

**特点**

- 线程安全（synchronized）
- **不允许 null key/value**
- 性能一般，设计老旧

**建议**

- 现在更常用 `ConcurrentHashMap`

### LinkedHashMap

**特点**

- 在 HashMap 上维护链表顺序
- 可以按插入顺序迭代
- 也可按访问顺序（可做 LRU 缓存的核心）

**适用场景**

- 需要可预测遍历顺序
- 想实现简单 LRU
